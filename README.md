# Fraud Detection with NL Alerts

A portfolio ML project that flags fraudulent card transactions and tampered ID documents
and explains each flag in plain English: a supervised model for scoring, SHAP for
explainability, and a RAG-grounded LLM layer that turns the explanation into a natural-language alert.

> Portfolio project on simulated data, not production-grade.

## Architecture

```
Transactions -> feature engineering -> LightGBM (fraud score)
             -> SHAP (per-prediction feature attribution)
             -> RAG retrieval (FAISS fraud-pattern knowledge base)
             -> Gemini (grounded natural-language alert)
             -> FraudEvent -> FastAPI (Docker) -> Next.js dashboard (Vercel)

Document images -> ResNet18 + Grad-CAM -> same alert layer (not yet served by the API)
```

## Stack

Python | LightGBM | scikit-learn | SHAP | PyTorch | FAISS | Gemini API | FastAPI | Docker | Next.js

## Performance

Held-out test set: 555,719 transactions, 2,145 fraud (0.39%). Generated by `python scripts/performance_matrix.py`.

| Model | Operating point | Precision | Recall | F1 | ROC-AUC | PR-AUC |
|---|---|---|---|---|---|---|
| LightGBM | default (thr 0.500) | 0.268 | 0.938 | 0.417 | 0.996 | 0.828 |
| LightGBM | best F1 (thr 0.989) | 0.828 | 0.712 | 0.766 | 0.996 | 0.828 |
| LightGBM | 90% recall (thr 0.747) | 0.378 | 0.900 | 0.532 | 0.996 | 0.828 |
| Random Forest | default (thr 0.500) | 0.545 | 0.866 | 0.669 | 0.994 | 0.807 |
| Random Forest | best F1 (thr 0.752) | 0.771 | 0.755 | 0.763 | 0.994 | 0.807 |
| Random Forest | 90% recall (thr 0.350) | 0.399 | 0.900 | 0.553 | 0.994 | 0.807 |

LightGBM was chosen for its higher PR-AUC and roughly 7x faster training (12 s vs 80 s); its default 0.5 threshold is misleading, so the API's `block` (0.989) and `manual_review` (0.747) thresholds come from the precision-recall curve. Document model (ResNet18, tampered class): precision 0.928, recall 0.77, accuracy 0.807, on synthetic copy-move tampering of MIDV-2020 images. Thresholds were derived on the test set, so treat these figures as optimistic.

## Data

The datasets are not included in this repository (size and licensing). To retrain or re-run the pipeline, download them into `rawdata/`:

- **Transactions:** the Sparkov simulated credit card dataset, "Credit Card Transactions Fraud Detection Dataset" by kartik2112 on Kaggle. Place `fraudTrain.csv` and `fraudTest.csv` in `rawdata/`.
- **Identity documents:** MIDV-2020, from its official release by the dataset authors. Extract it to `rawdata/midv2020/`. `scripts/03a_prepare_tamper_dataset.py` generates the synthetic copy-move tampered images from it.

The API itself does not need either dataset. The serving artifacts (`lightgbm.joblib`, `shap_explainer.joblib` and the `rag_index/`) are committed under `outputs/`, so `pytest` and the Docker image work from a fresh clone.

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements-api.txt pytest httpx   # full pipeline: requirements.txt
cp .env.example .env     # set FRAUD_API_KEY; add your Gemini key and ENABLE_ALERTS=1 for alerts
pytest -v                # no Gemini key or network needed
uvicorn src.api.main:app --reload --reload-dir src --port 8000    # docs at /docs
```

Docker: `docker build -t fraud-api . && docker run --rm -p 8000:8080 --env-file .env fraud-api`
